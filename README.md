# QSkill Internship – Task 1: CSV Data Analysis

## Objective
Load a CSV file using Pandas, perform basic data analysis, create charts/visualizations, and write observations.

## Dataset
`student_performance.csv` is a clean sample student-performance dataset prepared for this task.

Columns:
- Student_ID
- Name
- Age
- Math
- Science
- English
- Attendance

## Tools/Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## How to run
1. Open Google Colab.
2. Upload `QSkill_Task_1_Data_Analysis.ipynb`.
3. Upload `student_performance.csv` into the Colab session.
4. Run the notebook cells from top to bottom.
5. Check that the tables, charts, heatmap, and observations appear.
6. Keep the notebook saved with the outputs.

## Deliverables
- Completed Jupyter/Colab notebook
- CSV dataset
- Screenshots/outputs if QSkill asks for them

## Important
The notebook calculates observations from the actual data, so the numerical results are not manually guessed.
